# 随手纯本地记账 (AutoLedger) — Android 原生离线自动记账项目

本项目是一个**100% 纯本地、零联网权限**的 Android 自动记账应用，专为个人隐私记账设计。
通过读取**银行动账短信**、**微信支付通知/界面**、**支付宝通知/界面**，自动提取收入与支出金额，并弹出快捷窗口记录**「这笔钱用来干什么」**。

## 核心特性
1. **物理级断网隐私保障**：`AndroidManifest.xml` 中完全不申请 `android.permission.INTERNET` 权限，所有账单数据仅保存在手机本地 SQLite 数据库。
2. **三合一自动捕获**：
   - **短信监听 (`SmsReceiver`)**：自动识别各大银行储蓄卡/信用卡消费、入账、转账短信。
   - **通知栏监听 (`PaymentNotificationService`)**：实时拦截微信支付凭证、收款到账通知与支付宝交易提醒。
   - **无障碍支付识别 (`PaymentAccessibilityService`)**：针对付款后不弹通知的情况，自动识别微信/支付宝「支付成功」页面上的金额与商户名称。
3. **3 秒快速备注 (`QuickRecordActivity`)**：捕获账单后自动弹出半透明底部卡片，预填金额、收支类型、渠道与商户，只需输入「用来干什么」（或点选常用标签：餐饮、买菜、交通、购物、娱乐、居家、人情、工资）即可保存。
4. **本地统计与 CSV 导出 (`MainActivity` & `DatabaseHelper`)**：支持按月统计总支出/总收入、按用途搜索筛选、内置正则解析测试器，以及一键导出 `CSV` 表格到手机 `Download` 目录。

## 如何生成 APK 安装包（两种方式任选）

### 方式一：免安装环境，使用 GitHub 云端自动打包 APK（最简单）
本项目已内置 `.github/workflows/build-apk.yml` 云端自动编译脚本：
1. 在 GitHub 创建一个私有仓库（Private Repository），将解压后的全部文件上传上去。
2. 点击仓库顶部的 **Actions** 标签页，等待 `Build AutoLedger APK` 工作流自动运行完成（约 2 分钟）。
3. 在运行结果页面底部的 **Artifacts** 区域，直接下载编译好的 `AutoLedger-debug.apk` 到手机安装即可。

### 方式二：使用 Android Studio 本地打包 APK
1. 打开 **Android Studio**（建议 Hedgehog 或更新版本），选择 **Open** 打开解压后的 `AutoLedger` 文件夹。
2. 等待 Gradle 自动同步完成，点击顶部菜单 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**。
3. 编译完成后，在 `app/build/outputs/apk/debug/app-debug.apk` 获取安装包并传到手机安装。

## 手机端安装后权限开启指南
由于 Android 系统对短信、通知监听和无障碍服务有严格保护，首次安装打开 APP 后，请点击主界面顶部的三个快捷授权按钮：
1. **开启短信读取权限**：允许接收并解析银行动账短信。
2. **开启通知使用权**：在系统「通知使用权」列表中找到 **随手纯本地记账** 并打开（Android 13+ 若提示「受限制的设置」，请先去系统「设置 -> 应用 -> 随手纯本地记账 -> 右上角三个点 -> 允许受限制的设置」后再开启）。
3. **开启无障碍服务**：在系统「无障碍 / 已安装的服务」中开启 **随手纯本地记账支付页面识别**。
